# AgentMonitor_Project

Integrated AgentMonitor project (MAS + monitor + feature aggregator + benchmark runner + trainer).

See project README in previous messages for usage steps.

Key commands:
- Run single prompt: `python Agent_Monitor/run_with_monitor.py`
- Run benchmarks: `python Agent_Monitor/benchmark_runner.py`
- Train XGBoost: `python Trainer/xgb_trainer.py`
- Predict: `python Trainer/predict.py`
